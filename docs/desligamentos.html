6  Vínculos Desligados em 31/12 – RAIS

Os gráficos seguintes são relativos as declarações de trabalhadores que não permaneceram em seus postos de trabalho até o final do ano. Assim, a filtragem dos registros será dada pela coluna Ind.Vínculo.Ativo.31.12 == "NÃO", em que o NÃO representa os vínculos desligados.

6.1 Motivo do Desligamento

A análise dos vínculos desligados revelou dinamismo na movimentação de desligamentos, cujos padrões se reconfiguraram em três fases distintas ao longo do período longitudinal.

Em 2023, o mercado de trabalho exibiu uma situação atípico de mobilidade voluntária: os pedidos de demissão quase dobraram em relação a 2022 (22 → 36), enquanto as demissões por iniciativa do empregador e os términos de contrato por prazo determinado recuaram (78 → 63 e 32 → 24). Esse padrão sugere que a retomada pós-pandemia de grandes projetos de licenciamento ambiental ampliou as oportunidades de escolha dos profissionais ou que a migração para o regime MEI (Microempreendedor Individual) atraiu arqueólogos para fora do mercado formal.

Em 2024, o padrão retornou ao nível de 2022, com queda expressiva nos pedidos de demissão por iniciativa do empregado (36 → 23). A reversão indica que o pico de 2023 foi um evento conjuntural, não uma tendência estrutural. A estabilização indica uma menor disponibilidade de oportunidades vantajosas para os trabalhadores.

Em 2025, o campo laboral se reconfigurou novamente: pedidos de encerramento de vínculos e demissões patronais voltaram a crescer, enquanto os términos de contrato por prazo determinado despencaram −59,4% em relação a 2024 (32 → 13). Essa queda abrupta sugere que houve menos contratos temporários formalizados ou convertidos em vínculos indeterminados.

Paralelamente, as transferências entre empregadores cresceram de forma constante, indicando uma maior articulação entre consultorias para alocação de profissionais especializados em projetos específicos. E as demissões por acordo mantiveram participação no quadriênio, sinalizando que a rescisão negociada também é um mecanismo utilizado na profissão.

Mostrar código executado 
desligados <- Arqueo.RAIS.2022_2025 %>% 
  dplyr::filter(Ind.Vínculo.Ativo.31.12=='NÃO') %>% 
  mutate(Motivo.Desligamento = recode(Motivo.Desligamento,
                           "DEM SEM JC" = "Rescisão sem Justa Causa - Empregador",
                           "DESL POR ACORDO" = "Rescisão por Acordo",
                           "DESL SEM JC" = "Rescisão sem Justa Causa - Empregado",
                           "FALECIMENTO" = "Falecimento",
                           "POSS OUT CAR" = "Posse em Outro Cargo Inacumulável",
                           "TERM CONTR" = "Término do Contrato de Trabalho",
                           "TRANS S/ONUS" = "Transferência de Empregado sem Ônus")) %>% 
  group_by(Ano, Motivo.Desligamento) %>% 
  summarise(quantidade= n()) %>% 
  dplyr::select(Ano, Motivo.Desligamento, quantidade) %>% 
  mutate(Motivo.Desligamento = factor(Motivo.Desligamento, 
                           levels = c("Rescisão sem Justa Causa - Empregador", 
                                      "Rescisão sem Justa Causa - Empregado",
                                      "Término do Contrato de Trabalho", 
                                      "Transferência de Empregado sem Ônus",
                                      "Rescisão por Acordo", 
                                      "Posse em Outro Cargo Inacumulável", "Falecimento"))) |> 
  mutate(Ano = as.factor(Ano))

desligados |>
  group_by(Motivo.Desligamento) |>
  e_charts(Ano) |>
  e_bar(quantidade) |>
  e_title(
    text = "Mercado de Trabalho Formal de Arqueólogos - RAIS 2022 a 2025",
    subtext = "Distribuição dos Motivos do Desligamento",
    left = "center",
    textStyle = list(fontSize = 15, fontWeight = "bold"),
    subtextStyle = list(fontSize = 12, fontWeight = "bold")
  ) %>%
  e_tooltip(
    extraCssText = "text-align: left;",
    trigger = "item",
    formatter = htmlwidgets::JS("
      function(params) {
        return 'Ano: ' + params.name + '<br/>' +
               params.marker + ' ' + params.seriesName + ': ' + params.value[1];
      }
    ")
  )

6.2 Desligamento por Sexo

O desligamento por sexo revela um contraste entre os gêneros que reflete, em parte, a própria evolução dos vínculos ativos. Os arqueólogos lideram numericamente as saídas do mercado formal, mas essa liderança vem encolhendo progressivamente ao longo do período - um reflexo direto do crescimento dos vínculos ativos masculinos, que mantém mais homens no mercado e, consequentemente, reduz o volume de desligamentos.

As arqueólogas, por outro lado, apresentaram um comportamento distinto. O aumento nos vínculos ativos femininos não se traduziu em redução proporcional nas saídas. Os desligamentos desse gênero sobem em ritmo acelerado (+46,8% no acumulado), indicando que a entrada de novas arqueólogas no mercado formal não está sendo acompanhada pela mesma taxa de retenção observada entre os homens.

Em 2025, os números absolutos de desligamentos se cruzam, com 69 saídas registradas para cada sexo. Contudo, interpretar esses valores absolutos isoladamente é enganoso, pois o estoque total de vínculos ativos cresceu 30,27% no quadriênio. Um volume estável de saídas sobre uma base maior significa, na verdade, menor rotatividade relativa. O melhor indicador comparável para essa análise é, portanto, a taxa de desligamento, conforme mostrado na Tabela 6.1.

Mostrar código executado 
sexo.desligado <- Arqueo.RAIS.2022_2025 %>%
  dplyr::filter(Ind.Vínculo.Ativo.31.12=='NÃO') %>% 
  group_by(Ano, Sexo) %>%
  summarise(quant.sexo= n()) %>% 
  ungroup() %>% 
  dplyr::select(Ano, Sexo, quant.sexo) |> 
  mutate(Ano = as.factor(Ano),
  Sexo = factor(Sexo, 
                           levels = c("MASCULINO", "FEMININO")))

sexo.desligado %>%

Nesse recorte, o quadro se inverte. A taxa geral de desligamento recuou de 31,94% em 2022 para 26,49% em 2025, evidenciando que a rotatividade da categoria diminuiu em termos proporcionais, ainda que o número absoluto de saídas tenha permanecido praticamente estável em 138 registros nos dois extremos do período. Quando se desagrega por sexo, porém, os movimentos vão em sentidos opostos: a taxa masculina caiu de forma contínua, de 34,73% para 24,04%, enquanto a taxa feminina subiu, de 27,65% para 29,49%.

É por isso que o aparente empate observado em 2025 (69 desligamentos) mascara uma realidade distinta: essas saídas incidem sobre bases muito desiguais - 234 declarações femininas contra 287 masculinas. Em outras palavras, a entrada crescente de arqueólogas no mercado formal não tem sido acompanhada pela mesma capacidade de retenção que o mercado oferece aos arqueólogos, resultando em uma taxa de rotatividade feminina que, ao contrário da masculina, vem se agravando ao longo do período.

Mostrar código executado 
taxa_geral <- Arqueo.RAIS.2022_2025 %>%
  group_by(Ano) %>%
  summarise(
    Ativos     = sum(Ind.Vínculo.Ativo.31.12 == "SIM"),
    Desligados = sum(Ind.Vínculo.Ativo.31.12 == "NÃO"),
    .groups = "drop"
  ) %>%
  mutate(
    Total = Ativos + Desligados,
    Taxa  = round(Desligados / Total * 100, 2),
    Grupo = "Total"
  )
 
taxa_sexo <- Arqueo.RAIS.2022_2025 %>%
  group_by(Ano, Sexo) %>%
  summarise(
    Ativos     = sum(Ind.Vínculo.Ativo.31.12 == "SIM"),
    Desligados = sum(Ind.Vínculo.Ativo.31.12 == "NÃO"),
    .groups = "drop"
  ) %>%
  mutate(
    Total = Ativos + Desligados,
    Taxa  = round(Desligados / Total * 100, 2),
    Grupo = dplyr::recode(Sexo, "FEMININO" = "Feminino", "MASCULINO" = "Masculino")
  ) %>%
  dplyr::select(-Sexo)
 
tabela_taxa <- bind_rows(taxa_geral, taxa_sexo) %>%
  mutate(Grupo = factor(Grupo, levels = c("Total", "Feminino", "Masculino"))) %>%
  dplyr::select(Grupo, Ano, Ativos, Desligados, Total, Taxa) %>%
  arrange(Grupo, Ano) %>%
  gt(rowname_col = "Ano", groupname_col = "Grupo") %>%
  tab_header(
    title    = "Taxa de Desligamento",
    subtitle = "Vínculos encerrados sobre o total de declarações do ano-base"
  ) %>%
  cols_label(
    Ativos     = "Ativos em 31/12",
    Desligados = "Desligados",
    Total      = "Total declarado",
    Taxa       = gt::html("Taxa de<br>desligamento")
  ) %>%
  fmt_integer(columns = c(Ativos, Desligados, Total), sep_mark = ".") %>%
  fmt_number(columns = Taxa, decimals = 2, dec_mark = ",", pattern = "{x}%") %>%
  cols_align(align = "center", columns = c(Ativos, Desligados, Total, Taxa)) %>%
  tab_style(style = cell_text(weight = "bold"), locations = cells_row_groups()) %>%
  tab_style(
    style     = list(cell_text(weight = "bold", color = "#2c5f8a"),
                     cell_fill(color = "#eef4fb")),
    locations = cells_body(columns = Taxa)
  ) %>%
  tab_source_note(
    source_note = gt::md("Taxa = desligados ÷ (ativos + desligados) × 100")
  )
 
tabela_taxa
